<h2 align="center">🚀 Sobre mim</h2>

<img
  align="right"
  src="./assets/astro-removebg-preview.png"
  width="280"
  alt="Ilustração de desenvolvedor"
/>

Sou **Yorg**, estudante de **Análise e Desenvolvimento de Sistemas** e desenvolvedor Full Stack, com foco na construção de aplicações web completas.

Atuo principalmente com **Java e Spring Boot** no backend e **React, TypeScript e JavaScript** no frontend. Também trabalho com integração de APIs, bancos de dados e construção de interfaces responsivas.

Atualmente, venho aprofundando meus conhecimentos em **arquitetura de APIs, OpenAPI First, automação com inteligência artificial e engenharia de dados**.

Entre meus projetos estão aplicações web corporativas e uma plataforma inteligente para criação e edição de vídeos curtos, com geração automatizada de cortes e possibilidade de ajustes manuais.

Meu objetivo é escrever código limpo, criar sistemas confiáveis e continuar evoluindo como desenvolvedor, unindo **desenvolvimento Full Stack, dados e inteligência artificial**.
